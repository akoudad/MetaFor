## Try it yourself

1. Start a Chat and ask about a subject you want to explore.
2. Select an interesting passage, choose **Ask about this**, and send a focused
   follow-up. Follow its topic, then return to the original passage.
3. Open the conversation map to see the connections. Reopen the conversation
   through **Saved chats**, or export an `.ingx` copy.
4. On Mac, press **Option + M** while another app is open. Ask for an explanation
   or translation, then continue in Chat if you want to explore further.

Add your own API key before trying live generation. Help sends a screen snapshot
with each question and requires Screen Recording permission.
